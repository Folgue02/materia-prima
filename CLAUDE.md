# Main task
This must be a platform where users can login to the platform, and log their spendings on food shared by the team.


# Users

## Admin
An admin should be able to:
1. Create accounts for other users
2. Create 'foods' where users will log their spendings on.

## Users
1. Join 'foods' where they will spend money
2. Remove themselves from it
3. Log spendings on it
4. Be able to see how much money he has spent in total
5. See a full listing of the food funds he is subscribed to.
6. See a list of the food funds he can subscribe to.


# Food funds

They have a name, records on which user has spend how much everytime they register their spending

There is a list of users subscribed to them.

Everytime a user registers an spending, the page should show the next user that should spend money on it, working like a roulette so all users spend more or less the same amount of money.
**NOTE**: This doesn't mean that the page enforces the quantity the user spends, the next user who's chosen
to pay is on an order not based on the paid money.

There should be a number to show how much money has been spent on the food fund of that kind, and how much money has spent that food fund in specific.
